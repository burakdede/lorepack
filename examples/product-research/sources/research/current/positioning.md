# Launch Positioning

Lorepack is the build system for AI context.

The homepage should lead with the lifecycle: plan, build, validate, activate, diff, deploy and
rollback. Retrieval is useful because it reads an immutable build with provenance. Retrieval is
not the product category.

## Audience

The first audience is a developer or team lead who already gives agents a directory full of
notes, spreadsheets and project files. The wedge is trust: they need to know which context was
served, why it was selected, and whether it can be rolled back.

## Launch Message

Say: "Git and Terraform for the context your AI depends on."

Avoid saying that Lorepack is a local RAG server. That framing hides the build lifecycle and
makes rollback sound like an implementation detail.
