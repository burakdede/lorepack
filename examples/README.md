# Examples

These are small checked-in Lorepack projects used by the README demo and by CI.

| Example | Shows | Walkthrough |
|---|---|---|
| `product-research/` | current and archived research notes, declared supersession, CSV table import | [`product-research/README.md`](product-research/README.md) |
| `coding-project/` | architecture records, current notes, draft notes, coding-oriented export | [`coding-project/README.md`](coding-project/README.md) |

Run the demo against both examples:

```bash
pnpm demo:readme
```

Check drift without rewriting the transcript:

```bash
pnpm demo:readme:check
```
