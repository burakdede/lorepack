# XLSX reader spike

The measurements behind [`docs/architecture/adr-xlsx-parser.md`](../../docs/architecture/adr-xlsx-parser.md),
kept so the decision can be re-run rather than believed.

`spike-own-reader.mjs` is the ~150 line proof that a read-only reader on `yauzl` and `sax`
returns cell addresses, formula text, full merge ranges and correct types, and that it holds
85 MB at the 500,000-row envelope. It is **not** production code: #75 implements the real
parser against the golden-fixture harness. This file exists so the numbers in the ADR are
reproducible.

```bash
node --experimental-strip-types benchmarks/xlsx/spike-own-reader.mjs <file.xlsx> [sheet]
```

It needs `sax` and `yauzl`, which the workspace has once #75 lands. Fixtures are generated by
the harness in that ticket; the ADR records how the 500,000-row file was produced.

Measured 2026-08-04 on the development machine, Node 24.18.1, Linux x64:

| Reader | 500,000 rows | Peak RSS | Wall clock |
|---|---|---|---|
| own (`yauzl` + `sax`) | 2,000,004 cells | **85 MB** | 14.3 s |
| `exceljs` streaming | same | 297 MB | 4.9 s |
| `read-excel-file` | same | 899 MB | 6.2 s |
