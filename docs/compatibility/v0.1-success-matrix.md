# v0.1 Success-Criteria Matrix

Date: 2026-08-20.

This matrix maps the sixteen section 26 MVP success criteria to committed evidence. It is the
pre-release audit for issue `#102`; the release-only rows become final only after the v0.1.0
publish workflow and post-publish smoke complete.

## Core Primitive Gate

These five local primitives are mandatory foundations for the v0.1 release. Each row names both
the focused tests that exercise the implementation and the functional acceptance path that
proves the behavior through the product boundary.
